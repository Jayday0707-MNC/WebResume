Four full-stack projects, from a community reporting platform and a multi-tenant SaaS to my final-year placement platform.

Mend

Community outage reporting, 2026

Residents report water, power and road faults by dropping a pin on a map. Neighbours confirm an existing report instead of filing a duplicate, and moderators move each one through to resolved, with a public history.

It catches duplicates by distance (within 250 m), marks a report as confirmed once enough people are affected, and checks moderator roles against the database. A public status page shows progress without personal data, with locations rounded to about 100 m and rate-limited APIs.

React (Vite), Leaflet, Node.js, Express, PostgreSQL (Neon), JWT

Triage

Multi-tenant helpdesk SaaS, 2026

A helpdesk where every organisation gets a private workspace. Each query is scoped to the organisation ID in the user's token, so one customer can never see another's tickets.

It has JWT authentication, bcrypt password hashing and role-based access for admins, agents and customers, plus a PostgreSQL schema, a REST API for tickets, comments and users, and a React dashboard with a status overview.

React (Vite), Node.js, Express, PostgreSQL (Neon), JWT
