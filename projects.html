Triage

Multi-tenant helpdesk SaaS, 2026

A helpdesk where every organisation gets a private workspace. Each query is scoped to the organisation ID in the user's token, so one customer can never see another's tickets.

It has JWT authentication, bcrypt password hashing and role-based access for admins, agents and customers, plus a PostgreSQL schema, a REST API for tickets, comments and users, and a React dashboard with a status overview.

React (Vite), Node.js, Express, PostgreSQL (Neon), JWT
